# mihomo-config-builder v0.2.5

This patch release adds `anytls://` node URI support for mixed `nodes.txt` sources.

## Highlights

- `nodesFile` inputs can now convert `anytls://` lines into Mihomo `type: anytls` proxies.
- The parser supports common AnyTLS URI parameters including `sni`, `alpn`, `fp`, `allowInsecure`, `insecure`, `idle-session-check-interval`, `idle-session-timeout`, and `min-idle-session`.

# v0.3.1

Replace visible hexadecimal node suffixes with readable numbers (`东京 01`,
`东京 02`), ordered deterministically within each location. Add Chinese names for
Mumbai, Moscow, San Francisco, Hanoi, Bochum, Gelnhausen and Kerkrade.

Adding/removing same-location nodes can renumber peers. Integrations should
preserve selections by endpoint identity, as the NixOS integration does.

# v0.3.2

Preserve the `优化` label from original subscription and manual node names as
`optimized: true` in dashboard metadata. Names remain compact and unchanged.

The label survives source merging, geographic renaming and later metadata
exports. It belongs to the endpoint, not its IP, and works without IP metadata.
Only the recognized flag is retained; raw source names are not exported.

This label records the provider or owner description; it does not infer a
specific route or measure performance.

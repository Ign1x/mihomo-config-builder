- Vendor Go dependencies and build a static CLI without module downloads.
- Cache parsed remote sources privately; preserve the last accepted response on
  transport or content errors. Add explicit offline builds.
- Do not turn a failed subscription URL into an HTTP node.
- Atomically write configurations with private permissions; redact URL path tokens.
- Add cached IP location naming for subscriptions and manual nodes; preserve
  separate endpoints that share a label and rewrite routing references.
- Add explicit background metadata refresh and sanitized dashboard export commands.

Protocol and inferred routes are absent from names. Network metadata describes
server IP ownership, not confirmed proxy exits. Metadata refresh is never required
for configuration generation or daemon startup.
